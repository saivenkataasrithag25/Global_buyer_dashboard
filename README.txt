GLOBAL BUYER DISCOVERY DASHBOARD — VERSION 2

Purpose
A beginner-friendly front-end prototype to organize potential international buyers for Indian singing bowls and track export outreach.

Run
1. Extract this ZIP.
2. Open index.html in Chrome.
3. Bootstrap is loaded from a CDN, so internet access is needed for the styling and modal.
4. Data is saved in the browser's localStorage on that device/browser.

Features
- Buyer records with company/person, country, email, phone, website, category and research source
- Search and filters by buyer type, lead source, outreach status and email format
- Add, edit and delete buyers
- Basic email-format validation and duplicate-email prevention
- Outreach status and follow-up date tracking
- Dashboard counts for prospects, email formats, contacted prospects and follow-ups due
- CSV import and export
- Email draft opened through the device's configured mail app
- Product presentation file picker (manual attachment step)
- Responsive Bootstrap layout

Important limitations (be transparent in your submission)
- Sample buyer records are illustrative and are NOT verified leads. Replace them with real research before presenting them as actual buyers.
- Email validation checks only syntax, not whether an inbox exists or accepts messages.
- Buyer classification is keyword-based, not AI/ML.
- This is a browser-only prototype. Data is local to the browser and is not shared across devices or users.
- The selected presentation file is not automatically attached to the email. Attach it manually in your email app.
- No emails are sent automatically. The email app opens a draft for review.
- CSV import expects column headers such as Name, Country, Email, Phone, Website, Category, Source, Status, Follow-up, Notes.
